# Tree Daily 参考排版模板

- **保存路径**：`<TREE_ROOT>/outputs/daily/YYYY-MM-DD-<核心主题>.md`（`outputs/` 默认在 `.gitignore` 中，不进 `01~04` 慢变量与 Git 历史）。
- **每日一份**：早间生成后，日内或晚间刷新时直接原地更新同一天文件，补齐 `## 今日记录` 并勾选已完成事项。

---

## 参考 Markdown 结构（可按个人定制灵活调整）

```markdown
---
date: 2026-11-24
theme: "核心主题直白概括"
---

# 2026-11-24 · 核心主题直白概括

> 一句话串起昨天收尾、今天已做或最值得盯住的一件事（大白话，≤50字）。

## 昨日复盘

- **工作**：昨天 00:00–24:00 在各项目上实际推进的动作、拍板与产出。
- **学习**：昨天输入的新知、拆解的竞品/源码、收藏或消化的文章与播客。
- **生活**：昨天的作息活跃时段、饮食/采购、运动健康或生活事项进展（客观记录事实）。
- **卡点与未决**：昨天还没拍板或偏离计划的地方（没有可省略）。

## 今日记录

- **工作**：今天截至目前已经推进或完成的工作事项。
- **学习**：今天已经阅读、调研或消化的学习输入。
- **生活**：今天的作息起点、饮食采购、运动或日常状态记录。
```
