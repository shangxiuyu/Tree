# Tree Daily Markdown 契约（Schema v1）

> 本文件同时是 **Agent 输出规范**、`tree daily lint` **机检规则** 与 **Web 前端零成本解析契约**。任何字段名和层级均由 `tree daily write` 自动强校验。

---

## 一、文件位置与命名

- **目录**：`<TREE_ROOT>/outputs/daily/`（所属 `outputs/` 默认由 `.gitignore` 忽略，不随 `tree sync` 推远端，不进入 `01~04` L0 上下文；未来周报、专题调研等其他消费型输出同样按子目录归入 `outputs/`）。
- **命名**：`YYYY-MM-DD-<核心主题>.md`（主题 4~12 字，直白说清当天主线，无空格及路径非法字符）。
- **每日唯一（支持日内动态刷新）**：每天早间生成 1 份，日内或晚间刷新时由 `tree daily write` 原子覆盖同日文件，补充/更新 `## 今日记录` 并勾选已完成聚焦项。

---

## 三、`tree daily lint` 强制校验清单（前端解析保证）

以下规则由代码硬卡，**任何一项不通过都会被 `tree daily write` 拦截**：

1. **Frontmatter**：必须含 `schema_version: 1`、`date`、`theme`、`status`（`ready | reviewed`）、`generated_at`、`updated_at`、`sources_ok`、`sources_skipped`、`feed_count`（非负整数）；行内或块级数组中含冒号的项必须加双引号。
2. **必需板块、固定 H2 标题名与自定义板块扩展**：`## 昨日复盘`、`## 候选沉淀`、`## 今日聚焦` 为必含板块（缺失将被拦截）；严禁把动态时间戳塞进 `##` 标题里；纯离线模式设 `feed_count: 0` 时允许省略 `## 今日专属 Feed`。`## 昨日复盘` 与 `## 今日记录` 统一按 `- **工作**：`、`- **学习**：`、`- **生活**：` 三维度梳理（`## 昨日复盘` 缺少任一维度时 `lint` 会发出告警）；用户通过 `04-我如何工作/tree-daily/SKILL.md` 个人定制区新增的任意固定 `##` 板块（如 `## 今日吃什么`、`## 关注行情`）均天然通过校验，前端对非内置 H2 统一按通用 Markdown 卡片渲染，无需改代码。
3. **Feed 卡片严格结构**：
   - 标题行必须是 `### N. [来源] 标题`，`[来源]` 必须在受控枚举内：`GitHub` / `即刻` / `小宇宙` / `X` / `B站` / `知乎` / `博客` / `论文` / `社区` / `播客` / `视频` / `报告` / `产品` / `新闻`。
   - 每张卡片**只允许且必须包含以下 4 个单行字段**（禁止重复键名、禁止扩展键名、禁止嵌套子列表）：
     - `- **结论标签**：` 仅允许 `[必看原文]`、`[看这3句就行]`、`[只听片段 ...]`
     - `- **关联**：` 关联页面与一句话理由
     - `- **要点**：` 单行紧凑干货（建议 ≤180 字）
     - `- **链接**：` 至少包含 1 个标准 Markdown 链接 `[名称](https://...)`（无直链即熔断；与过去 14 天历史及当天内均自动去重）
   - `feed_count` 必须严格等于实际卡片数；`## 顺手清一篇旧藏` URL 同样受 14 天及当天去重校验。
4. **候选沉淀机器可读格式**：每条由代码强校验为 `- [ ] \`create|update|append\` \`相对路径.md\` — 提炼结论与理由`（或 `今日无须入树`），方便前端一键映射为 `tree write` 动作。
5. **隐私与反自白底线**：禁止正文出现 `## 采集说明`、系统自白、非 URL 正文中的内部会话哈希 ID、15 位以上疑似订单号及明文密钥（URL 内的 X 推文 ID 与 UUID 自动豁免）。
