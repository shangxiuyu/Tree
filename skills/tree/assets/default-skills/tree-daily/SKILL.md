# Tree Daily — 个人日报写作指南

本指南位于 `04-我如何工作/tree-daily/`，是生成个人日报的唯一真源。想加新板块（如“今日吃什么”）、换信息源或调整语气，直接修改文末「四、我的个人定制」即可。

核心原则：**每天只维护 1 份完整日报（早间复盘昨日、日内或晚间刷新补录今日所做）；客观梳理工作、学习、生活三维事实，不凑水贴、不说教，直接写文件到 `<TREE_ROOT>/outputs/daily/`。**

---

## 一、日报结构（可按文末个人定制自由增减）

1. **`## 昨日复盘`**（按「工作 / 学习 / 生活」三维度全景梳理）：
   - `- **工作**：` 昨天 `00:00–24:00` 推进了哪些项目、做了什么拍板、解决了什么问题。
   - `- **学习**：` 昨天调研拆解了什么方案、阅读或收藏了什么有启发的内容。
   - `- **生活**：` 昨天日常饮食/采购、运动健康、作息活跃起止时段与生活事项进展（客观记录事实，不隐藏、不说教）。
   - `- **卡点与未决**：`（可选）昨天还没闭环的事项。
2. **`## 今日记录`**（日内/晚间刷新或复盘今天时出现，同样按 **`工作 / 学习 / 生活`** 梳理截至当前已做的事，并勾选已完成的聚焦项；早间刚出刊尚无新进展时可省略）。
3. **`## 候选沉淀`**（0~2 条）：从昨日/今日挑出值得长期记入 Tree 的慢变量，标明建议动作与目标路径；没有则写 `今日无须入树`。**未经用户确认，严禁直接修改 `01~04`。**
4. **`## 今日聚焦`**（1~3 件）：从尚未闭环的事和当前重点项目中自然长出来，写清背景与完成标准。
5. **`## 今日专属 Feed`**（3~6 条；离线无搜索工具时可省略）：基于用户画像精选的高信号内容，附直链与阅读建议。
6. **可选扩展板块**：`## 顺手清一篇旧藏`（0~1 条）、`## 明日预热`，以及文末定制区约定的任何个人板块。

## 二、执行流程（纯文档驱动，无需专属 CLI）

### Step 1：读人与盘点轨迹
1. 运行通用查询命令了解用户背景与近期轨迹：
   ```bash
   tree context
   tree recent --days 7
   tree chat list --limit 20
   ```
   *(若 `tree context` 提示 `幼苗未破土`，先问用户身份与最关注的 1~2 个方向，不盲推热搜。)*
2. 查看 `<TREE_ROOT>/outputs/daily/` 下最近几期日报：
   - 承接上一期的未决事项与聚焦项；
   - 扫一眼近 14 天已经推荐过的文章/播客链接，避免重复推荐。
3. 把本机线索分拣进「工作 / 学习 / 生活」三个篮子（结合活跃项目仓库 `git log`、跨端会话 `tree chat read` 及宿主已挂载的社区/生活工具；有什么写什么，严禁脑补未发生的细节），并遵守 `04-我如何工作/` 中的沟通与文风要求。

### Step 2：采样与选品（宁缺毋滥）
按 [references/feed-sources.md](references/feed-sources.md) 结合宿主可用搜索/社区/播客工具采样，淘汰掺水内容：
- **跨维度配额**：单一手头项目最多占 2 条（至少 1 条找反方视角、翻车复盘或竞品实招）；至少 2 条覆盖用户的其他长期关切或跨界视野。
- **实读与直链**：每条必须读到一手内容并附上真实可点击的 `[名称](https://...)` 单篇直链，拿不到直链直接舍弃；每条标明 `[必看原文]`、`[看这3句就行]` 或 `[只听片段 mm:ss]`。
- **离线/异常降级**：无联网工具时直接省略 Feed，严禁编造假链接；某个工具报鉴权/超时错误时静默跳过，仅在需用户重登凭证时于文末留一行简短提醒。

### Step 3：直接落盘至 `outputs/daily/`
参照 [references/daily-template.md](references/daily-template.md) 组织排版，直接用文件写入工具保存至：
`<TREE_ROOT>/outputs/daily/YYYY-MM-DD-<核心主题>.md`
- **隔离边界**：`outputs/` 默认已被 `.gitignore` 忽略，**严禁调用 `tree write` 写日报**。
- **同日刷新**：同一天内再次刷新时，直接更新当天已有的那份文件（若当天主题微调改了文件名，顺手删掉同日旧文件，保持每天只留 1 份）。
- **隐私检查**：不要把明文 API Key/Token 或原始长订单号/身份证号写进日报。

## 三、文风避坑速查

| 雷区 | ❌ 避免写法 | ✅ 推荐写法 |
| :--- | :--- | :--- |
| **漏掉学习与生活** | 只写“昨天改了 3 个脚本”，学习与生活只字不提 | 按工作、学习、生活三条完整梳理昨日拍板、阅读输入与作息采购状态 |
| **拍马屁附和** | “恰好印证了你的方向，给出官方背书” | “原文实验数据正好反驳你现在的做法：过度写死规矩反而让模型变笨” |
| **自造黑话** | “收束出跨目录特征嗅探方案，构建消费层母体” | “定了按当前目录挑上下文的思路，先用日报跑通每天看一遍的习惯” |
| **家长式说教** | “近十天少绿叶菜，晚饭记得带份青菜，早点睡” | “昨日活跃时段 09:02–16:54；上次生鲜采购在 6 天前，按一周周期余量充足” |

## 四、我的个人定制（优先级最高，随时直接改这里）

- **阅读时长与三维梳理**：控制在 2 分钟内扫完；`## 昨日复盘` 与 `## 今日记录` 统一按「工作 / 学习 / 生活」三维度梳理。

- **信息源微调**：*(暂无额外限制，默认按我的 Tree 画像自动推导)*
